Alert perspectives

Alert ในแต่ละมุมมอง (ทำงานใน POC แล้ว 14 ข้อ)

แต่ละมุมมองตอบ control ของ ISO/IEC 27001:2022 ต่างกัน ส่วน threshold เป็นค่าตั้งต้นที่ต้องปรับตามข้อมูลจริงใน Phase 1

Threatภัยคุกคามและ threat intel

  • HIGHTHR-01 IDS alert priority 1 (malware, exploit, C2)
  • HIGHTHR-02 firewall ปล่อยผ่าน traffic ไปหรือมาจาก IP ใน TI list
  • HIGHTHR-03 DNS query ไป domain phishing หรือ C2

ISO A.5.7 · A.8.7 · A.8.23

Identity & accessการเข้าถึงและสิทธิ์ admin

  • HIGHIAM-01 brute force หน้า GUI firewall (≥5 ครั้ง/5 นาที)
  • HIGHIAM-04 VPN brute force ต่อ user
  • MEDIAM-02 admin login จากนอก Management zone
  • MEDIAM-03 admin login นอกเวลา 19:00–07:59

ISO A.8.2 · A.8.5 · A.6.7

Networkขอบเขตและการแบ่ง zone

  • HIGHNET-01 port scan: ≥15 port ต่างกันใน 1 นาที
  • HIGHNET-02 Guest พยายามเข้า Server/LAN/Mgmt

ISO A.8.20 · A.8.22

Web filteringการใช้งานเว็บ

  • MEDWEB-01 เครื่องเดิม query หมวดที่ถูกบล็อก (พนัน, ลามก, P2P) ≥ 10 ครั้ง/ชม.
  • MEDWEB-02 พยายามเลี่ยง DNS filtering ผ่าน DoT, DNS ภายนอก หรือ DoH

ISO A.8.23 · A.8.20

Change & log healthconfig และความต่อเนื่องของ log

  • LOWCHG-01 ทุกการแก้ config บอกว่าใคร จาก IP ไหน และแก้หน้าไหน
  • HIGHOPS-01 OPNsense หยุดส่ง log 5 นาที (เครื่องล่ม, สายหลุด หรือมีคนปิด logging)
  • HIGHOPS-02 ตรวจ SHA-256 ของ log archive ไม่ผ่าน (ไฟล์ถูกแก้หรือหาย)

ISO A.8.9 · A.8.32 · A.8.15 · A.8.16 · A.5.28

Next phaseมุมมองที่ควรเพิ่ม

  • Login สำเร็จหลัง fail หลายครั้ง (correlation)
  • Switch/AP: MAC ใหม่ที่ไม่อยู่ใน DHCP static mapping
  • IDS alert เดิมซ้ำจากเครื่องเดิม (เครื่องที่น่าจะติดเชื้อ)
